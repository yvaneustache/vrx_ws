L'image TabAPF_robmooc.png donne les equations des apf.
Développe un noeud ROS2 permettant de conduire le drone à une position et un cap précis pour entrer dans un dock.
2 cas sont définis : 
1) le drone est devant le dock, il est attiré par la position du dock et par le cap du dock.
2) le drone est derrière le dock, il est repoussé dans le dock et est attiré par l'inverse du cap du dock.
Les équations sont données dans le fichier controller.py. Roblib.py est aussi disponible dans le repertoire.

2 wam-v sont définis dans vrx_gz avec la config two_wamv.yaml. Le deuxième est le dock, le premier est le drone à contrôler.
